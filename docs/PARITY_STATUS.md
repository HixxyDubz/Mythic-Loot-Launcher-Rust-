## Verification snapshot

- `cargo test --manifest-path src-tauri/Cargo.toml`: 57 passed and one explicit live-source acceptance harness ignored by default, including public catalogue validation/local-state preservation, atomic remote cache replacement, safe catalogue-key profile IDs, minimal CurseForge/Modrinth bootstrap formats, current/legacy Minecraft launcher roots, backward-compatible sync-target persistence, schema/config recovery, bundled manifests, adversarial paths, streaming hashes, deterministic single/multipart publishing, privacy scanning, cached-asset revalidation, multipart reconstruction rejection, fail-closed GitHub actions, update rollback, restore staging and Safe Launch recovery guards.
- `npm run test`: 14 passed, including asynchronous public catalogue merge, Developer modpack creation, native-absence fail-closed behavior, Player publisher-removal and Smart Launch clean, update-confirmation and unsafe-path flows.
- Player frontend build passed with 1,832 modules transformed and zero Publisher/Modpack Manager UI, public-metadata fields, publishing IPC or former preview-data identifiers in its output; Developer passed with 1,835 modules and the expected Developer workspace identifiers.
- Player's exact `--no-default-features` native suite passed 47 tests. The full Developer/default suite passed 57 tests with one explicit live-source harness ignored.
- Clippy passed with warnings denied for both `--all-features` Developer and `--no-default-features` Player targets.
- `npm run package:windows`: two NSIS installers and two portable win-unpacked executables built into edition-specific folders with one SHA-256 manifest.
- Browser visual check: the Update & Repair, Recovery history and Safe Launch workspaces passed at 1180x760 and 940x640 without horizontal overflow. Safe Launch truthfully showed that the bundled manifest has no optional extras, omitted the unavailable Start action, remained readable and logged no browser warnings or errors.

## External acceptance boundary

Server acceptance is not a launcher gate because servers are managed elsewhere. Publication of the first real `launcher-catalog.json`, a full real-package GitHub update/repair, real large-installation restore, authenticated GitHub repository creation/release publication of the locally verified multipart assets, real import of the generated CurseForge and Modrinth bootstrap profiles, installation of both NSIS editions, a real configured-game Smart Launch, a real-game Safe Launch using a trusted manifest with optional files, and friend-machine modpack acceptance are not part of this checkpoint.
